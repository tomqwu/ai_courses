#

"Tests passed" vs. evidence“测试通过” 与证据 M1
Counts without a command, date, environment, and revision are a claim; evidence is auditable.没有命令、日期、环境和版本的计数只是一个说法；证据是可审计的记录。
.nojekyll禁用 Jekyll 的标记文件 M9
An empty file that tells GitHub Pages to publish the files as they are, without running Jekyll. Hidden by default because its name starts with a dot. Lives in catalog-starter/.nojekyll.一个空文件，让 GitHub Pages 按原样发布文件，而不运行 Jekyll。
403 vs. 404 for a foreign id对他人 id 返回 403 还是 404 M5
403 confirms the resource exists; 404 is the anti-enumeration answer because the lookup happens inside the actor's tenant.403 暴露资源存在；404 防止枚举，因为查询按租户限定。
:cloud alias:cloud 别名 M0 M2
a model a local daemon serves from a remote backend. The name ends in :cloud or -cloud, or /api/tags reports a remote_host/remote_model. ListenToMe/Sources/ListenToMeCore/ModelRanking.swift:66-72; course/03-content/m02-ondevice-app/tinycopilot/src/tinycopilot/model_router.py.以 :cloud 结尾的 Ollama 模型名，背后是托管服务，而不是本机权重。
[NEEDS CLARIFICATION][待澄清] 标记 M4
The template's marker for an unresolved decision; the gate requires zero remaining before planning. — SignUpFlow/.specify/templates/spec-template.md.模板中未决问题的标记；关卡要求在计划前全部清零。
[P] vs. [US#][P] 与 [US#] 标记 M4
[P] marks a task parallelizable with its neighbours (different files, no dependency); [US#] ties the task to the user story it serves. They are orthogonal, not synonyms.[P] 表示可与相邻任务并行；[US#] 标明任务属于哪个用户故事。

A

A passing badge vs. recorded evidence通过徽章与记录的证据 M8
a badge is a current status; an evidence record is a command, its counts, a date, and its limits. Only the second survives a gap review.徽章只显示当前状态；证据记录包含命令、计数、日期和限制。
Absolute path绝对路径 M9
A folder address that starts from the top of the disk, such as C:\Users\ada\code or /Users/ada/code. It means the same thing wherever you are. Lives in lesson.md, Segment M9.2.从磁盘顶层开始的文件夹地址。
Acceptance criteria验收标准 M8
Concrete, testable conditions a story must satisfy, written Given/When/Then. The capstone's dimension 1 fails when criteria are vague. Where: SignUpFlow/specs/014-security-hardening/spec.md; 03-content/m08-launch-capstone/lab.md step 2.故事必须满足的具体、可测试条件，按 Given/When/Then 书写。
Acceptance criteria vs. success criteria验收标准与成功标准 M0 M4
Acceptance criteria describe one scenario's observable outcome (blocked 15 minutes); success criteria are the feature-level measurable targets (100% of brute-force attempts blocked). Both live in spec.md, and mixing them makes both ungradable.验收标准说明故事何时完成；成功标准说明功能是否达成业务目标。
Acceptance gate验收关卡 M5
The point where the product must be proven operable, not merely functional: playbook scenarios, disruption drills, and a manifest that admits unproven rows. (SignUpFlow/docs/playbooks/coverage.json; docs/playbooks/church.md)产品必须被证明可运营（而不只是功能可用）的检查点。
Acceptance scenario验收场景 M4
A Given/When/Then statement inside a user story whose Then-clause is an observable, numeric outcome. — SignUpFlow/specs/014-security-hardening/spec.md (US1).用户故事中的 Given/When/Then 陈述，其 Then 部分可观察、可量化。
Adjective-wedge形容词楔子 M7
The leading adjectives of a positioning one-liner that carry the differentiator — the part a competitor would have to rebuild to match. Lives in the derived one-liner at ListenToMe/docs/competition-analysis.md:88.定位一句话中承载差异点的开头形容词。
AGENTS.md通用智能体规则文件 M1
The cross-agent baseline rules file that tools such as Codex CLI, Cursor, Aider, Jules, OpenHands, Sourcegraph Amp, and Factory read natively; an open format stewarded by the Agentic AI Foundation under the Linux Foundation. Keep one, and have CLAUDE.md import it with @AGENTS.md. In SignUpFlow it is 188 lines. (SignUpFlow/AGENTS.md:3)多数编码智能体都会读取的跨工具基线规则文件。
Anti-hallucination rules防幻觉规则 M1
Prohibitions that make fabricated facts checkable: do not invent paths, names, commands, or identifiers; grep before referencing; read facts from the canonical source; offer 2–3 options when a request is ambiguous. (SignUpFlow/AGENTS.md, "Anti-hallucination")让编造内容可被检查的禁令：不得虚构路径、名称、命令或结果。
Archetype产品原型 M0
One of the three product shapes this course builds: on-device app, spec-driven SaaS, expertise product. They differ in technical center of gravity, not in method. — course/03-content/m00-orientation/lesson.md本课程构建的三种产品形态之一：端侧应用、规格驱动 SaaS、专业知识产品。

A dict classifying every mounted route as public/ member/ admin, paired with a test that compares the dict to the live route table and to each route's dependency tree. (SignUpFlow/api/route_auth_policy.py:8-171; test in tests/unit/test_api_route_auth_policy.py)把每个路由归类为公开/成员/管理员，并用测试强制执行的表。

The section of a constitution that fixes what an agent may do alone. SignUpFlow's: YOLO Mode: DISABLED, Git Autonomy: ENABLED (Commit changes when done). (SignUpFlow/.specify/memory/constitution.md, "Autonomy Configuration")宪章中规定智能体可以独立做什么的部分。
