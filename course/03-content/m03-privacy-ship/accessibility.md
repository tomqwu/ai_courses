# Accessibility M3 — Privacy, Testing, Shipping

> Applies to `slides.md`, the three scripts in `video-scripts.md`, and the lab. The deck renders
> with no external assets, so nothing here depends on downloading a visual.

## Deck accessibility

The `aps` theme is built for the dark-background contrast rule: its own header states that "body
text and code on dark background exceed WCAG AA (7:1+)" (`course/06-production/slides/aps.css:3-4`).
Its base body size is 30px (`aps.css:22`), headings 40–52px, and code blocks 0.82em
(`aps.css:69-71`). Keep all substantive text at body size; the theme's smaller sizes (0.55em–0.66em)
are for metadata and footers only.

**Never encode meaning in colour alone.** The theme's accents always carry a label — for example the
privacy deck marks proof slides with the literal word "**Proof**" in the heading, not a colour or
icon. If you add any visual, it needs alt text that states the same claim as the slide's pointer;
a diagram that repeats a table is better rebuilt from the table than drawn.

Every slide carries a speaker note as an HTML comment. Because notes are comments, they do not
render on the slide but do remain in the exported HTML source — treat them as part of the
transcript deliverable, not private scratch.

## Code accessibility

Keep code lines at or under 100 characters so terminal capture and the 0.82em code size stay
readable at 1080p. When a pointer appears on a slide, **say it aloud as well as showing it**:
"open ModelPrivacy dot swift, lines seventeen to twenty-four." A learner on an audio-only path
cannot see the monospace path, and a learner reading a transcript cannot see the screen.

Read code as intent, not punctuation. Instead of "guard let info equals try question JSON
serialization," say "if the daemon's JSON cannot be parsed, return false." The privacy lesson is
about the default failure path; narrate the default.

## Transcript structure

The recording scripts are already chaptered by segment and beat. Export them with chapter markers
keyed to the beats table timestamps (0:00, 0:30, 1:30, and so on), one marker per row, so a learner
can jump to the metadata guard without scrubbing. Use speaker labels — `[INSTRUCTOR]` for
narration, `[SCREEN: <file>]` for on-screen actions — and keep the ~130 words/min pacing that the
scripts are budgeted for; faster delivery makes captions dense and unreviewable.

## Captions

Caption everything read aloud, including commands and file paths. Spell paths out in caption text
("ListenToMe slash Sources slash ListenToMeCore slash ModelPrivacy dot swift, lines 15 to 24")
rather than relying on autogenerated punctuation. Caption the shell prompts and the counts
("49 passed", "201 passed", "2 skipped") as spoken words — those numbers are the evidence, and an
autocaptioner will render "49 passed" as "49 past".

For terms that are not English words, caption the intended form and gloss it once in narration:
Ollama, notarize/notarization, stapling, notarytool, notarization. Say "Ollama, the local model
daemon" the first time, and "notarization, Apple's automated security check" once. Where a
competitor name is used, caption the exact spelling shown in `ListenToMe/docs/competition-analysis.md`
rather than a phonetic guess.

## Accommodations

- **Extended time.** The lab is honest at ~3 hours; offer up to double time for Steps 3 and 4
  (coverage-floor demonstration and the sourced table), which are the most reading- and
  writing-heavy.
- **No-audio path.** `handout.md` must suffice on its own: mental model, decision table, commands,
  pointers, gotchas, and the "you're done when…" checklist. A learner who cannot attend the live
  session can complete the lab from the handout plus `lesson.md`.
- **Two-outcome labs are an equity feature.** A machine with only `:cloud` aliases is not a
  deficient machine. Local-only mode correctly rejects everything there, and the documented
  record is a written daemon note — and the contract test still runs, because it is a contract
  test, not a privacy test. No student is blocked
  by hardware, and no student should feel pressure to weaken a privacy check to "get the lab
  working."
- **Screen-reader path.** Every repository reference in this module is written as inline code with
  a file path and line range, so a screen reader announces one stable string. Announce the same
  string in narration.
