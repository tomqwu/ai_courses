# 实验 M5 — 评分细则：隔离与验收

## 自动不通过（无论其他各项如何，都判实验 M5 不通过）

1. **伪造证据**——编造的 pytest 汇总、手工改过的计数，或者任何命令都产生不了的输出
   （`01-design/assessment-and-rubrics.md`）。
2. **在取数之后才用 Python 做租户过滤**——他人的数据行已经被读出来了；控制措施从来就不在查询里。
3. **漂移测试或校验器运行为绿，却没有记录任何人为引发的失败**——从未见过防护生效，所以它未经证明。
4. **为了通过而削弱测试**——`mini-flow/tests/test_lab*.py` 下除取消跳过之外的任何改动、把 `404`
   放宽为 `4xx`、删除一条断言，或者删除清单中的一行而不是把它标为 `blocked`。
5. **在隔离层级中模拟鉴权**——租户隔离的证据必须来自真实 JWT 请求，经由起始项目的
   `tests/support.py` 辅助函数或等价手段发出。
6. **为你自己的工作声称有独立评审**——见 `SignUpFlow/docs/ai-pr-review.md` 中本地评审检查清单
   （Local Review Checklist）第 3 项。
