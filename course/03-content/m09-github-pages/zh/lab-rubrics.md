# 实验 M9 评分细则 — 发布你的产品目录

## 自动不通过（只要出现其中任何一条，无论得分多少，实验都判为不通过）

1. **伪造输出**——环境检查、`git status` 或 `git log` 的输出是重新手打的、被编辑过的，或者与 GitHub 上的仓库对不上。
2. **别人的产品目录**——已发布的地址不是学员自己的仓库。
3. **在页面上收款**——GitHub Pages 网站上有购物车、银行卡表单或任何形式的收款。GitHub 自己的条款禁止用 Pages 经营线上业务或电子商务网站（`github.com/github/docs`，`content/pages/getting-started-with-github-pages/github-pages-limits.md`）。
4. **提交了机密信息**——仓库或其历史中的任何位置出现密码、令牌或私钥。
