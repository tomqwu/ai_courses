# 实验 M4 — 评分细则

## 自动不通过的情形

以下情形无论其他各项如何，都判实验 M4 **不通过**（依据 `01-design/assessment-and-rubrics.md`，伪造是唯一的不通过项）：

1. **伪造证据**——任何并非由其声称的命令、会话或人产生的 grep 记录、检查清单输出或陌生人报告；`Counts` 被改过或 Q/A 行被删掉的报告。
2. **一条引用的路径不存在且未被修复**——包括仓库使用 `alembic/versions/` 时那个真实存在的 `migrations/versions/` 漂移。
3. **一份没有漂移检查输出的自评检查清单**——写着 "all checks passed"，却没有记录任何 grep 或重数。
4. **没有 `tasks.md`**——没有它，文件夹就无法接受陌生人测试，所以通过关卡无法达成。
5. **关卡运行之后，`spec.md` 中仍留有实现泄漏**——语言、框架或模式 SQL。
6. **仍有未解决的 `[NEEDS CLARIFICATION]` 标记**，却照样产出了计划或任务。
