# 测验 M7 — 变现：定价、包装与定位

> 8 道题：6 道选择题 + 2 道简答题 · 约 10 分钟 · 下方附答案表，含理由和目标对照

**Q1 (MC).** MacWhisper 的 Pro 档一次性售价约 $69，而 Granola 收费约 $14–35/用户/月。一次性定价在什么情况下胜出？

- A) 你想压低对手的标价，快速增长
- B) 产品完全在用户的机器上运行，所以你的每用户成本不会每月重复发生
- C) 这个品类中的每个竞争对手都是免费的
- D) 你打算在售出后停止维护产品

**Q2 (MC).** SignUpFlow 的计费和短信路由已在 API 下注册，但在 `BILLING_ENABLED=false` / `SMS_ENABLED=false` 之下返回 404。这个模式教给你什么？

- A) 把核心工作流放在计费后面门控，逼用户升级
- B) 功能就是档位——每个档位都应该增加一个看得见的功能
- C) 先把付费路径建好，用开关关闭，并且永远不让核心工作流依赖它们——在工作流可信之后再变现
- D) 把门控藏起来，让买家在购买之后才发现局限

**Q3 (MC).** 下面哪种 AI × QE 漏斗的顺序是正确的，并且每个阶段确认的东西也正确？

- A) 问卷 → 免费站点 → 无上限的长期顾问费 → 试点
- B) 免费证据站点（信任）→ 问卷（匹配度）→ 固定费用探查（预算与发起人）→ 带继续/终止关口的有上限试点（是否扩大规模）
- C) 免费证据站点 → 付费试点 → 打折的探查 → 订阅
- D) 冷邮件 → 免费试用 → 企业合同

**Q4 (MC).** 你的 macOS 应用通过你自己的结账流程一次性售价约 $69。上架应用商店会增加触达，从每一单中抽成，推高订阅预期，并且拥有客户记录。「按渠道经济学选择」意味着：

- A) 选商店——触达是会复利增长的变量，抽成不过是分发的成本
- B) 出于原则坚持直销——任何平台抽成都是价值损失，无论它换来了什么
- C) 按每个渠道实际让你付出的代价来定价——分成比例、谁控制价格、谁拥有客户（因而谁拥有邮箱地址）——这就是为什么同一个产品可以在直销时一次性收费，在商店里采用订阅或终身买断；而直销之所以可行，只是因为你已经有了 M3 中签名并经过校验和验证的发布流水线
- D) 在两个渠道都以完全相同的价格和模式上架，这样比较保持诚实，买家自行选择

**Q5 (MC).** 你的直播班定价 $1,500，包含项目、反馈和社区。按照直播价比例规则，自学档应该是：

- A) 约 $150——自学版大约是直播价的 10%，因为视频的交付成本很低
- B) 与直播班相同，因为内容是一样的
- C) 如果保留项目 + 异步反馈 + 社区，则为直播价的 70–85%——而一个光秃秃的录像库根本不应该出售
- D) $9.99，以匹配课程市场的定价

**Q6 (MC).** 你的桌面 copilot 默认在端侧运行。粘贴自己 API 密钥的用户每月不花你一分钱；在你的应用符合平台私有云模型免费档资格期间，由该模型服务的用户也不花你一分钱；按你假设的 token 费率，一个托管云端选项每个活跃用户每月约花你 $8.00。哪种定价结构与这些成本匹配？

- A) 对每个用户收取统一的月度订阅，把云端用户的成本分摊给所有人
- B) 一个一次性的 Pro，覆盖端侧、自带密钥和符合资格的私有云使用，再加一个可选的、有上限的月度云端档，定价高于它的 $8.00 成本线
- C) 按该品类约 $14/用户/月的价格按席位定价，因为对标区间就在那里
- D) 对每个用户（包括端侧用户）按 token 用量计费，让每张账单都成比例

**Q7 (short answer).** 你的产品：一个本地优先的 CLI，根据 git 历史起草发布说明，完全离线运行，MIT 许可证，另有一个面向团队的付费托管档。按 ListenToMe 的格式（形容词楔子 × 差异点 × 受众）写出定位一句话，加上一条你会发布的「这个产品不做什么」主张，并用一句话解释为什么这条主张能提高转化。

**Q8 (short answer).** 一个会议转写 Web 应用把音频发给一家云端 ASR 供应商，费用为每小时音频 $0.30，并把转写稿存储在你的服务器上。假设一个典型用户每月转写 20 小时，支付手续费为每笔 5% + $0.50。计算每用户的推理成本线和能覆盖它的最低月价，然后选择一种定价模式和第一档的价格，并用本模块中的一条对标规则，以三句话说明理由。

## Answer key

| Q | 答案 | 理由 | 目标对照 |
|---|---|---|---|
| 1 | B | 月费跟踪的是重复发生的每用户算力：Granola 和 Otter 每场会议都运行云端 ASR + 云端 LLM；MacWhisper 的 Whisper 在端侧运行，所以一次性约 $69 是合理的——「成本怎样重复发生，就怎样定价」。A 是「低价快速增长」的误解（`ListenToMe/docs/competition-analysis.md`）。 | M7.1 — 根据竞争证据为每种产品原型定价 |
| 2 | C | 「核心排班不得依赖任何一项付费集成」（`SignUpFlow/AGENTS.md`）；付费路径已注册但由开关门控；变现日后以配置的形式发布。A 和 B 是经典误解（「门控核心来逼用户升级」；「功能就是档位」）；D 违反了诚实局限规则。 | M7.1 — 功能门控的理由 |
| 3 | B | 漏斗在 `ai_qe/index.md` → `/discovery/` 中清晰可见；固定费用探查（“no client price or start date has been agreed”，`engagement.json`）和由发起人签字的继续/终止关口确认预算和规模（`course/00-research/03-ai-qe-deep-read.md` §1、§4）。 | M7.1 — 漏斗各阶段及每个阶段确认什么 |
| 4 | C | MacWhisper 是一个天然实验：同一个应用在 Gumroad 上一次性约 €59/$69，在 App Store 里是 $6.99/月–$99.99 终身（`ListenToMe/docs/competition-analysis.md:34`），所以渠道改变的是模式，而不只是标价。要据以定价的三个变量是分成比例、价格控制权和客户所有权——正是这三个变量让课程市场只能用于获客（M7.2，Udemy）。A 把触达当成免费的；B 把本应逐个产品计算的事情变成了一条规则；D 与证据相矛盾——两个渠道定价完全相同，忽视了商店是用你的利润和你的客户记录来换取触达。直销之所以可行，完全是因为 M3 的发布纪律（在测试过的提交上打标签，产物经过校验和验证）已经存在（`ListenToMe/docs/RELEASING.md:33-36`）。 | M7.2 — 按渠道经济学选择平台 |
| 5 | C | 只有保留项目 + 异步反馈 + 社区时，自学版才 = 直播价的 70–85%；「一堆 Zoom 录像不是自学课程」（`course/00-research/02-course-market-research.md` §C）。 | M7.2 — 直播价比例规则 |
| 6 | B | 逐个档位地，成本怎样重复发生就怎样定价：端侧、自带密钥和符合资格的私有云用户每月都不产生成本，所以一次性价格适合他们（即 BYOK 折扣）——不过只有第一种可以作为「端侧」来销售（M3.1 的三个层级）；只有托管云端档的成本会重复发生，所以只有它按月收费，定价高于它的成本线并设有上限（混合）——即 M7.2 中 TinyCopilot 的底线（`course/03-content/m07-monetize/lesson.md`）。A 让端侧用户为一笔并非他们造成的成本纳税——这正是买家可以做的审计；C 只从区间取价，而没有考虑成本结构；D 计量的是你并不为之付费的算力。 | M7.1 — 定价分类：每种模式匹配什么、惩罚什么 |
| 7 | 参考答案：「面向小团队的免费、开源、完全离线的发布说明 copilot——自带仓库，历史保持私密，一条命令起草说明。」每个分句都必须对应一个表格列或能力（免费/开源 ← 价格/许可证行；完全离线 ← 隐私列；自带仓库 ← BYO；一条命令 ← 工作流）。诚实的主张，例如：「它起草的是基于提交、符合事实的说明——它不会编造你的提交无法支撑的路线图承诺。」为什么能带来转化：有限定的主张是一种溢价信号——读到局限的买家不再问「凭什么相信你」，而开始问「我们什么时候开始」（`course/00-research/03-ai-qe-deep-read.md` §3）。 | M7.3 — 定位一句话的推导；诚实主张带来转化的逻辑 |
| 8 | 参考答案：推理成本线 20 小时 × $0.30 = **每用户每月 $6.00**，重复发生；扣除手续费后要覆盖它，需要 0.95 × 价格 − $0.50 ≥ $6.00，所以价格 ≥ **$6.85**。模式：带 20 小时额度的按用户订阅（混合），第一档约 $12–15/用户/月，每个用户留下约 $4.90–7.75 用于覆盖固定底线。（1）每用户的云端 ASR 成本每月重复发生，所以一次性价格会成为一笔随使用量增长的补贴——订阅与成本结构匹配，而额度为重度用户设了上限（40 小时要花 $12.00）。（2）第一档落在 Otter 约 $8.33–16.99/用户/月的 Pro 区间之内，并与 Granola 约 $14 的 Business 价格持平——在你的表格显示的对标区间之内，且高于底线。（3）对标规则：价格买到的是明确的限额（转写时长、席位、保留期），并且有来源，符合定价表的约定（`ListenToMe/docs/competition-analysis.md`）。 | M7.1/M7.2 — 算出推理成本线，然后用一条对标规则选择模式 + 第一档价格 |

**评分说明（评分标准）。** Q1–Q6 自动评分；Q7–Q8 对照参考答案，按各自的三项检查评分：Q7（遵循格式；分句可追溯；局限能带来转化）和 Q8（算出推理成本线和覆盖它的价格；模式与成本匹配；价格在区间内并引用了对标规则）。没有单个测验的及格线：分数计入全课程的测验平均分，获得证书要求平均分 ≥75%（`01-design/assessment-and-rubrics.md`）。
